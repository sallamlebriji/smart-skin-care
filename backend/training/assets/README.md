The face-presence gate uses OpenCV's `haarcascade_frontalface_default.xml`,
copied unchanged from the official OpenCV 4.11.0 release:

https://github.com/opencv/opencv/blob/4.11.0/data/haarcascades/haarcascade_frontalface_default.xml

The original license/copyright notice is preserved in the XML header. This
is a face-presence heuristic only, not the trained wrinkle-severity model.
